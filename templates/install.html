Installation du plugin

Suivez ces étapes pour configurer RocketMax avec votre Rocket League.

Prérequis

  • Rocket League installé sur PC (version Steam ou Epic Games)
  • BakkesMod installé et fonctionnel
1

Télécharger le plugin

Rendez-vous sur le dépôt GitHub du plugin et téléchargez la dernière version.

Voir sur GitHub
2

Installer dans BakkesMod

Copiez le fichier .dll du plugin dans le dossier plugins de BakkesMod :

%appdata%\bakkesmod\bakkesmod\plugins\

Astuce : collez ce chemin dans la barre d'adresse de l'explorateur Windows.

3

Configurer le plugin

Lancez Rocket League avec BakkesMod. Ouvrez la console BakkesMod (F6) et vérifiez que le plugin est chargé correctement.

Le plugin enverra automatiquement vos données vers cette instance RocketMax.

4

C'est prêt !

Jouez quelques matchs en ranked et vos statistiques apparaîtront automatiquement sur la page des joueurs.

Voir les joueurs

Auto-hébergement (Docker)

Vous pouvez héberger votre propre instance de RocketMax avec Docker :

docker run -d -p 8080:5000 \
  -v rocketmax_data:/app/db \
  tellebma/backend-bakkesmod:latest
